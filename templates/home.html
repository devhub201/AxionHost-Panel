FAQ

Questions? Answered.

 

What are BOLTs?

BOLTs are the credits used to pay for servers. Earn them from daily rewards, quests, invites, boosts and promo codes.

What happens when my server expires?

It's suspended and you can renew any time. If it stays expired for {{ site.delete_after_days }} days it is deleted. Servers auto-renew when you have enough BOLTs.

Is crypto-mining allowed?

No. Miners are detected automatically and the server is suspended.

Can I run Docker?

Yes — container servers are configured Docker-ready.
